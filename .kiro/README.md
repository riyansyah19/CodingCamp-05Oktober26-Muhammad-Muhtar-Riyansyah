# Kiro project notes

Project: To-Do List Life Dashboard

Technical constraints from the assignment:
- HTML for structure
- CSS for styling
- Vanilla JavaScript only (no frameworks)
- No backend server
- Browser Local Storage for client-side data
- Keep exactly one CSS file in `css/` and one JavaScript file in `js/`

Required features:
- Current time/date and time-based greeting
- 25-minute focus timer with start, stop, reset
- Add, edit, complete, delete tasks; persist tasks with Local Storage
- Quick links that open websites and persist with Local Storage

Selected challenges:
- Light/dark mode
- Custom name in greeting
- Prevent duplicate tasks
